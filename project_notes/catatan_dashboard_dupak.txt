# Catatan Dashboard DUPAK

> Audit, bug fix, dan perbaikan pada DashboardController serta view-nya.

---

## Bug Critical yang Ditemukan

1. **Variable `$statistik` tidak di-pass ke view** — Admin login akan error `Undefined variable`.
2. **Breakdown KUM per komponen tidak dihitung** — Selalu menampilkan '0'.
3. **`$user->is_dosen` tidak aman** — Property belum tentu ada di model User.

---
