    - Nama MK, SKS, Jumlah Kelas
    - Tahun Ajaran (contoh: 2023/2024)
    - Semester (Gasal/Genap)
  
  AKUMULASI SKS PER SEMESTER dihitung dari:
    SKS_total = Σ (SKS × Kelas) untuk semua MK dalam 1 semester
  
  RUMUS AK:
    Jika SKS_total ≤ 10  →  Rate AK = 1.0 per SKS
    Jika SKS_total > 10  →  Rate AK = 1.0 untuk 10 SKS pertama,

  Contoh perhitungan dari mock data:
    - MI1264 Dasar Algoritma, 4 SKS, 2 Kelas
      SKS_total = 4 × 2 = 8
      8 ≤ 10 → Rate 1.0
      AK = 8 × 1 = 8
      
    - VII2B4 Pemrograman Web 2, 4 SKS, 2 Kelas (tapi dibagi):
      6 SKS × 1 kelas = 6 (rate 1.0) = 6
      2 SKS × 1 kelas = 2 (rate 0.5) = 1
      Total = 7 (karena SKS_total > 10)
      
  MAKSIMUM: 11 AK per semester
  
  Kolom Input User PER BARIS:

    - SKS
    - Jumlah Kelas
    - Tahun Ajaran (dropdown)
    - Semester (Gasal/Genap)
    - Link bukti (SK Mengajar)
  
  Kolom yang dihitung otomatis oleh sistem:

4. LOGIKA PERHITUNGAN ANGKA KREDIT (DETAIL)
================================================================================

--------------------------------
4.1 Pendidikan Formal (TETAP)
--------------------------------
  AK = Nilai baku sesuai jenjang
  Tidak ada perhitungan dinamis.
  
  Mapping ke ref_jenis_input:
    - id 101: Sarjana (S1)            → nilai_baku = 100.000
    - id 104: Magister (S2) linier    → nilai_baku = 50.000
    - id 105: Magister (S2) non-linier→ nilai_baku = 15.000
    - id 106: Doktor (S3) linier      → nilai_baku = 50.000
    - id 107: Doktor (S3) non-linier  → nilai_baku = 15.000

--------------------------------
4.2 Perkuliahan (DINAMIS - PRIORITAS TINGGI)
--------------------------------
  Input per baris: [Nama MK] [SKS] [Kelas] [Tahun] [Semester]
  
  Langkah 1: Kelompokkan semua MK berdasarkan (Tahun Ajaran + Semester)
  Langkah 2: Hitung SKS_total = Σ(SKS × Kelas) untuk kelompok tersebut
  Langkah 3: Tentukan rate per baris:
  
    for each baris in semester_group:
      sks_kelas = SKS × Kelas
      
      if SKS_total ≤ 10:
        rate = 1.0
        AK_baris = sks_kelas × 1.0
        keterangan = "SKS<=10"
      
      else:  // SKS_total > 10
        // Prioritaskan baris pertama dengan rate 1.0
        // Baris berikutnya yang menyebabkan SKS_total > 10 dapat dibagi
        
        // LOGIKA YANG DIPAKAI DI MOCK DATA:
        // Beberapa MK di-split manual:
        // Contoh: 4 SKS × 2 kelas = 8 total
        //         Tapi kalau total semester sudah >10, 
        //         MK baru bisa dibagi jadi (SKS_full × rate_1.0) + (SKS_excess × rate_0.5)
        
        // Implementasi yang lebih sederhana:
        // Sistem menghitung AK per baris berdasarkan proporsi
        // Jika SKS_total ≤ 10 → semua baris rate 1.0
        // Jika SKS_total > 10 → rate bervariasi (1.0 atau 0.5)
        // Pada mock data, rate ditentukan manual per baris
        
  MAKSIMUM: 11 AK per semester
  
  NOTE: Rate 0.5 pada mock data hanya muncul ketika SKS_total > 10.
  Ini berarti sistem perlu menghitung AKUMULASI semester terlebih dahulu,
  baru menentukan rate untuk setiap baris.

--------------------------------
4.3 Bimbingan TA/Skripsi (DINAMIS)
--------------------------------
  Input per baris: [Nama Mhs (NIM)] [Jenis] [Peran] [Tahun] [Semester]
  
  rate = 1.0 if Peran == "Pembimbing Utama"
  rate = 0.5 if Peran == "Pembimbing Pendamping"
  
  AK = 1 (volume) × rate
  
  MAKSIMUM TOTAL: 32 AK (untuk seluruh periode pengajuan)
  
  Sub-total Gasal + Sub-total Genap ≤ 32

--------------------------------
4.4 Penguji Ujian (DINAMIS)
--------------------------------
  Input per baris: [Nama Mhs (NIM)] [Peran] [Tahun] [Semester]
  
  rate = 1.0 if Peran == "Ketua Penguji"
  rate = 0.5 if Peran == "Anggota Penguji"
  
  AK = 1 (volume) × rate
  
  MAKSIMUM PER SEMESTER: 8 AK
    - Ketua Penguji max  : 4 AK per semester
    - Anggota Penguji max: 4 AK per semester
  
  NOTE: Perlu validasi real-time atau saat submit:
    if total_ketua_semester > 4 → ERROR/Warning
    if total_anggota_semester > 4 → ERROR/Warning
    if total_semester > 8 → ERROR/Warning

--------------------------------
4.5 Jabatan Pimpinan PT (TETAP per Semester)
--------------------------------
  Input per baris: [Jabatan] [Unit] [Tahun] [Semester]
  
  Mapping jabatan ke AK:
    f. Pembantu direktur akademi / ketua jurusan / bagian = 3 AK/semester
  
  AK = 1 (volume) × rate_jabatan
  
  NOTE: Jabatan lain (a-e, g-h) perlu konfirmasi nilai AK-nya.

--------------------------------
4.6 Lainnya (B, C, F, G, H, I, K, L, M)
--------------------------------
  Menggunakan nilai dari ref_nilai_kum_baku atau ref_jenis_input.
  Pada mock data mayoritas bernilai 0 karena belum diisi.

6. VALIDASI DAN BATASAN (BUSINESS RULES)
================================================================================

[Validasi Global]
1. Total AK per semester untuk Perkuliahan ≤ 11
2. Total AK Bimbingan TA (seluruh periode) ≤ 32
3. Total AK Penguji per semester ≤ 8
   - Sub-limit: Ketua ≤ 4, Anggota ≤ 4
4. Total AK Membina Mahasiswa ≤ 4
5. Total AK Mengembangkan Program Kuliah ≤ 2
6. Total AK Orasi Ilmiah ≤ 10

[Validasi Per Baris]
1. Semua field wajib diisi kecuali catatan
2. Link bukti harus valid URL
3. SKS, Kelas, Volume harus numeric dan > 0
4. Tahun ajaran format: YYYY/YYYY+1

[Validasi Khusus]
1. Sub-komponen K (Membimbing Dosen) dan L (Datasering):
   - Hanya muncul/aktif jika JFA dosen = Lektor Kepala ke atas
2. JFA menentukan apakah komponen tertentu bisa diakses

10. CATATAN IMPLEMENTASI PENTING
================================================================================

1. PERKULIAHAN memerlukan perhitungan AKUMULASI SEMESTER.
   Ini berarti saat user input baris baru, sistem harus:
   - Query semua baris existing dengan (Tahun + Semester) yang sama
   - Hitung SKS_total = SUM(SKS × Kelas)
   - Tentukan rate untuk baris baru (1.0 atau 0.5)
   - Update keterangan semua baris di semester tersebut

2. Bimbingan dan Penguji memerlukan DUAL INPUT:
   - Deskripsi (nama mahasiswa)
   - Peran (dropdown)
   - Keduanya mempengaruhi nilai AK

3. JABATAN memerlukan MAPPING TABEL khusus:
   - ref_jabatan_pimpinan_pt dengan kolom: kode, nama_jabatan, ak_per_semester
   - Atau bisa ditambahkan ke ref_nilai_kum_baku

4. Semua komponen memerlukan SEMESTER dan TAHUN AJARAN:
   - Kolom ini belum ada di tabel detail_pengajuan saat ini
   - Perlu ditambahkan

5. MOCK DATA menunjukkan SK terlampir sebagai bukti:
   - User input link ke dokumen (OneDrive/Google Drive)
   - Bukan upload file langsung

6. Kalkulasi AK untuk komponen dengan LIMIT harus menggunakan TRIGGER
   atau validasi di Controller, bukan hanya di Frontend.

7. Format mock data menunjukkan "rumus" di kolom yang kosong:
   - Ini adalah placeholder untuk formula otomatis
   - Jadi user TIDAK input AK manual, sistem yang menghitung
