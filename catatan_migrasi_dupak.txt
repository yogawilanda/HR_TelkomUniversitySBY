# Catatan Migrasi & Seeding DUPAK

> Struktur database, migrasi, seeding, dan aturan teknis multi-database.

---

## Arsitektur Database Multi-Connection

- **`sdm_tus`** (koneksi `mysql` / default) — database utama SDM
- **`dupak`** (koneksi `dupak`) — database modul DUPAK

### Aturan Penting
- Model DUPAK wajib extend `DupakModel` (sudah set `$connection = 'dupak'`).
- Query ke DB utama dari controller DUPAK pakai `DB::connection('mysql')`.
- **Tidak bisa Foreign Key constraint antar database**.

---

## Lokasi Migration DUPAK

```
database/migrations/dupak/
```

Format nama:
```
YYYY_MM_DD_HHMMSS_dupak_table_<nama_tabel>.php
```

Setiap migration DUPAK wajib:
```php
protected $connection = 'dupak';
```

---

## ⚠️ Aturan Penting: Jangan Buat Migration Baru untuk Alter Table

Tim menggunakan custom command:
```bash
php artisan db:full-refresh --seed
```

Command ini menghapus dan membuat ulang semua tabel, jadi:
- **Edit langsung migration existing** (file `create` table).
- Semua perubahan schema dilakukan di file migration yang sudah ada.
